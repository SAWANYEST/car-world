# CAR WORLD — النسخة المبدئية

موقع سيارات عربي تفاعلي، يحتوي على 6 سيارات مع الصور والبحث الفوري والتصفية والترتيب وعرض التفاصيل، وإضافة السيارات إلى المفضلة.

## تجربة الموقع

افتح ملف `index.html` في المتصفح مباشرة، أو انشره على Vercel باعتباره Static Website دون أي أمر Build. جميع الأنماط والبرمجة مضمنة في الملف لتسهيل التجربة للمبتدئين.

## المزايا

- ست سيارات ومعلومات مبسطة عنها.
- واجهة عربية RTL متجاوبة مع الكمبيوتر والجوال.
- بحث بالاسم أو الشركة أو الموديل.
- تصنيف سيدان ودفع رباعي وترتيب حسب السعر والموديل.
- تفاصيل كاملة في نافذة منبثقة.
- مفضلة تحفظ اختيارات المستخدم محليًا داخل المتصفح.

## تنبيهات مهمة

**الأسعار والمواصفات تجريبية/استرشادية** ولا تشكل عروض بيع أو بيانات رسمية للفئات السعودية. الصور مستضافة على Wikimedia Commons، وروابط المصدر والمصور وبيانات الترخيص ظاهرة داخل الموقع. قد تحتاج بعض الصور للتأكد من رخصتها قبل أي استعمال تجاري؛ وفي حالة فشل التحميل يظهر رسم بديل.

الموقع لا يتضمن تسجيل دخول أو قاعدة بيانات أو تحصيل أموال أو بيانات شخصية.
